# 終極電商 (Ultimate E-commerce)

具備會員分級、動態折扣規則、優惠卡券、紅利點數系統、智能贈品與加購引擎的 WooCommerce 擴充外掛。

由 快捷鍵Ctrl+A 開發維護。

## 變更紀錄

### 25.8.167
- 新增：每條折扣規則可選擇「套用到團購商品」（啟用團購模組時顯示在規則卡片底部）。商品打折、每件減價勾選後會在團購價上再折扣；滿額折扣、階梯折扣、免運、贈品、加購、買 N 送 N 取消勾選時，團購商品不算進門檻金額、件數與適用範圍，整單打折也只依非團購商品的金額計算。既有規則維持原本行為：商品折扣不套用到團購商品，其餘購物車類規則照常把團購商品算進去。
- 修正：團購頁最下方多出一段空白。底部購物車列的預留空間改為依購物車列實際高度計算，團購尚未開始或已結束（沒有購物車列）時不再預留。

### 25.8.166
- 新增：可自訂前台顯示的「團購」名稱與「團購主」稱呼（團購 → 設定 → 前台顯示名稱），例如改成「揪團」「揪團主」。套用到團購頁、倒數與提示訊息、購物車與結帳、訂單與 Email 上的商品欄位、會員中心專區；稱呼留空就用名稱加「主」。後台管理畫面維持「團購」，已成立訂單上的欄位名稱不會跟著改。

### 25.8.165
- 新增：團購頁商品有多張圖片（商品圖片＋商品圖庫）時，卡片圖片可以左右滑動，電腦上滑鼠移到圖片會出現左右箭頭，下方有圓點顯示目前第幾張；選擇規格時自動切換成該規格的圖片。
- 新增：團購頁底部購物車面板加上動畫：展開時從下方滑上、收合時滑下；增減數量時數字會彈一下，更新完成後該商品與小計短暫亮起；移除商品時該列滑出並收起，下方商品順勢補上。
- 改善：在團購頁加入購物車後，頁面會停在剛才的商品位置，不再跳回頁首。
- 改善：團購期間倒數改成「天／時／分／秒」數字方塊，結束前 24 小時改為紅色提醒。
- 改善：團購頁商品圖片改為依螢幕尺寸載入適合的大小，手機不再下載原尺寸圖片。

### 25.8.164
- 改善：團購頁商品卡片縮短。電腦與平板上數量框與「加入購物車」按鈕改為同一行，手機上維持各佔一行，商品描述超過約 3 行時先收合，點「看更多」展開。規格選單與數量、按鈕之間的多餘空白也已移除，「清除」選項移到規格名稱右側。
- 修正：網站裝有 Rank Math 或 Yoast SEO 時，團購頁的網頁標題、分享標題與 canonical 會被換成部落格頁的內容，搜尋引擎也會被告知可以收錄；現在團購頁一律顯示「團購名稱 - 網站名稱」、指向團購頁本身，並維持不收錄。
- 改善：團購主列表的「狀態」欄移到最前面，一眼就能看出哪些團購進行中；狀態標籤與下方的期間文字改為對齊，期間文字不再重複顯示「進行中」等狀態。

### 25.8.163
- 新增：團購模組（預設關閉，在「系統設定 → 模組開關」啟用）。管理員指定會員為團購主，每位團購主有專屬頁面 /group-buy/代碼/，只列出管理員替他指定的商品，目錄隱藏的商品也能放在團購頁販售；可變商品直接在專屬頁選規格。
- 新增：商品與各規格可設定「團購價」（須低於售價）。團員在專屬頁把商品加入購物車，該商品就以團購價結帳並歸屬該團購主；在一般商店或商品頁購買維持原價。同一張訂單可以同時有不同團購主的商品。團購價不疊加商品折扣規則，滿額折扣、點數、儲值金與優惠券照常使用。
- 新增：可個別設定每位團購主的折扣。在團購主編輯頁選「售價打折」（例如減 10% 就是打 9 折）或「每件減價」，套用到他所有團購商品與規格，以目前售價（特價中用特價）計算；也可以在「個別商品價格」表逐一指定商品或規格的價格。優先順序為個別商品價格 → 團購主折扣 → 商品上的團購價，表格會顯示每項目前實際生效的團購價。
- 新增：專屬頁是獨立的形象頁，不顯示網站選單、頁首與頁尾，商品卡不連到商品頁、簡短描述裡的連結也會移除，顧客在同一頁選規格與數量、加入購物車，再從底部購物車列直接前往結帳；外部與群組商品不放上團購頁。從團購頁進入的結帳頁與付款完成頁也使用相同的獨立版型（不顯示網站選單），只保留「返回團購頁」，金流、超商選店、點數與儲值金照常使用；從一般商店進入結帳則維持原本版型。
- 新增：團購佣金可設累進級距，依團購主的累計業績（已完成團購訂單的計佣金額，扣除取消與退款）超額累進計算，例如累計 3 萬以下 8%、3–10 萬 10%、10 萬以上 12%。可在團購設定建立全站級距，個別團購主可改用固定比例或自訂級距；下單當下的規則記在訂單上，已入帳的訂單不因之後升級回溯重算。會員中心團購主專區顯示累計業績與距離下一級的金額。
- 新增：團購頁可用 Elementor 設計。在 Elementor 建立範本，放入「團購」分類的團購名稱、團購簡介、團購商品小工具（可調每排商品數、間距、商品卡樣式），再到團購設定選為預設版型，或在個別團購主指定不同範本；未安裝 Elementor 或未選範本時使用內建版型。底部購物車列、不顯示網站選單與 CDN 快取的做法不變。
- 新增：團購頁可設定自訂網址（例如 /group-buy/amy/），由管理員在團購主編輯頁設定；原本的代碼網址仍然有效並自動轉到自訂網址。網址前綴 group-buy 也可在團購設定頁統一修改。
- 新增：專屬頁不使用 Cookie，內容對所有訪客相同，可交給 CDN 與伺服器快取；團購資格記在購物車項目上，購物車與結帳頁照常不快取即可。
- 新增：團購佣金紀錄。訂單完成時依團購商品的實付金額（含稅、不含運費，儲值金折抵算實付，全單點數折抵與滿額折扣依金額比例分攤）乘以佣金比例入帳，比例可設全站預設並個別覆寫，下單當下固定；取消或全額退款全數扣回，部分退款依退款商品或比例扣回，團購主本人下單仍享團購價但不計佣。
- 新增：每位團購主可設定團購開始與結束時間（選填，依網站時區）。開始前團購頁顯示開始時間與倒數，只預告商品與團購價、不能購買；進行中顯示結束倒數；結束後頁面顯示已結束，購物車裡尚未結帳的團購商品自動恢復原價並提示。後台團購主列表顯示未開始／進行中／已結束。
- 新增：團購頁底部購物車列可點開購物車面板，直接增減數量或移除商品，小計即時更新；加購品、贈品等特殊項目只顯示不能修改。面板展開時 LINE 浮動按鈕會暫時隱藏，收合後恢復；按鈕位置也會依購物車列實際高度自動避開。面板內容在瀏覽器端載入，團購頁仍可交給 CDN 快取。
- 新增：WooCommerce 訂單列表新增「團購」欄，顯示訂單所屬團購主與佣金狀態（未入帳、已入帳、已結算、已扣回）；列表上方可依團購主篩選，或選「所有團購訂單」只看團購單，點欄位裡的團購主名稱也能直接篩選。
- 新增：後台「團購」頁可管理團購主、查看佣金明細，線下匯款後按「結算」標記；已結算的佣金若之後被扣回，會記為負數在下次結算扣除。團購主在會員中心「團購主專區」可複製專屬頁連結、查看佣金與團購訂單；購物車、訂單與通知信的商品下方會標示所屬團購，訂單編輯頁側欄顯示各團購主的佣金。
- 修正：運送方式的補充名稱欄位與超商取貨欄位在部分情況下儲存時沒有寫入；改在 WooCommerce 設定儲存前就註冊欄位。

### 25.8.162
- 調整：點數新增、扣除與已套用提示的文字顏色改用主題色（新增用主題強調色、扣除用主題標題色），涵蓋會員中心點數紀錄與購物車／結帳的預估獲得、本次使用。

### 25.8.161
- 調整：外掛開發者名稱改為「快捷鍵Ctrl+A」，並移除外掛網址與作者網址。

### 25.8.160
- 修正：運送設定欄位使用完整註冊方式清單，不受區域快取影響；避免補充名稱掛鉤重複註冊，拒絕異常欄位輸入，退換貨設定保存補上明確權限與 nonce 驗證。
- 修正：綠界超商運送方式的編輯彈窗未顯示補充名稱欄位；改依實際運送方式物件讀取名稱，支援沒有網址 instance_id 的預先產生彈窗。
- 調整：訂單強化顯示偏好移至 WooCommerce → 設定 → 訂單強化；物流自動更新移至運送的「物流與訂單狀態」子頁。
- 調整：運送與付款名稱改在各方式的原生設定中調整，缺少名稱欄位或已有舊覆寫時提供補充欄位；沿用既有名稱設定，不改寫歷史訂單。
- 新增：地址強化、訂單列表單號、後台／顧客物流資訊及物流自動更新分別控制，未設定時維持原行為。
- 修正：關閉訂單強化後保留既有自訂狀態、已付款判定、搜尋、批次操作與退換貨處理；退換貨設定新增接受新申請開關，停用不阻斷既有申請。

### 25.8.159
- 改善：推薦連結與推薦人數合併至會員權益，移除獨立推薦碼頁籤；舊網址自動導向會員權益。複製成功僅在按鈕顯示勾選文字 3 秒，顏色跟隨主題。
- 修正：點數餘額、到期批次、歷程與訂單旗標改用共用會員鎖及交易；避免併發入帳覆蓋、同單重複發獎與餘額不足時併發超扣，寫入失敗整筆回滾，推薦碼與到期排程一併整合。
- 修正：多次部分退款改按累計比例結算點數；停用點數或儲值金模組後仍處理既有訂單退款。
- 修正：混合訂單的儲值商品退款不再誤扣一般商品等級消費額；完成訂單取消後立即更新會員消費額與等級。
- 修正：付款失敗後從訂單頁重新付款會補扣點數，餘額不足先中止，重複執行不重複扣點。
- 改善：移除後台說明的全域隱藏，重要操作提示直接顯示；較長的補充內容與信件變數改為可展開的詳細說明。
- 修正：推薦碼後台設定與推薦紀錄使用完整面板，欄位與說明排版統一為紅利點數模組樣式，確保獎勵規則與使用說明正常顯示。
- 新增：推薦碼功能，整合在紅利點數模組，可在「紅利點數 → 推薦碼」啟用；停用紅利點數會同時停止推薦碼新綁定與發獎。會員中心提供分享連結與直接複製按鈕，不顯示獨立推薦碼欄位，朋友點擊連結後在同一瀏覽器 30 天內建立新帳號自動綁定，不需輸入推薦碼，以首次有效來源為準，推薦關係建立後不能更換。
- 新增：新會員首筆訂單完成後，只給推薦人紅利點數，點數預設為 0，可在後台調整。訂單取消或全額退款會追回獎勵，部分退款保留，重複事件不會重複發獎；調整點數不會補發過去訂單。
- 新增：後台顯示最近 20 筆推薦紀錄與獎勵狀態。自動綁定沿用 WordPress 新會員與 WooCommerce 建立會員事件；社群登入及區塊版結帳須依外掛實測。來源使用簽章 Cookie，快取／CDN 須排除含 ref 參數的入口。

### 25.8.158
- 優化：會員退換貨列表省略未使用的總筆數查詢，並按會員隔離同次請求的申請快取。
- 優化：商品圖片替代文字只讀取該圖片使用的範本，減少重複設定讀取。
- 維護：整理開發文件與歷史紀錄，改善本機驗證工具的環境設定與失敗偵測。

### 25.8.157
- 調整：核准顧客的「取消訂單」申請時，不再自動取消綠界 7-ELEVEN 物流單。所有物流（7-ELEVEN、全家、萊爾富、OK、宅配）統一由你到綠界後台取消物流單，避免不同物流的行為不一致造成混亂；訂單有綠界物流單時，審核面板與訂單備註都會提醒你。

### 25.8.156
- 新增：核准顧客的「取消訂單」申請時，如果這張訂單已經在綠界建立 7-ELEVEN（C2C）物流單，系統會先自動向綠界取消物流單，再取消訂單並退款，不用再到綠界後台手動取消。物流單取消失敗（例如已經寄出）時不會核准，避免退款後貨還是送出去；如果你已經在綠界後台自己處理好，可以勾選「我已在綠界後台處理物流單」再核准。其他物流（全家、萊爾富、OK、宅配）無法自動取消，核准時會在訂單備註提醒你到綠界後台處理。

### 25.8.155
- 調整：退換貨的通知信（已收到申請、核准、拒絕、已收到退貨、換貨完成、訂單已取消、管理員新申請通知）寄件人改用「WooCommerce → 設定 → 電子郵件」設定的寄件人名稱與地址，跟 WooCommerce 原本的訂單信件顯示同一個寄件人。
- 調整：精簡取消訂單的通知信。核准取消並退款後，顧客只會收到 WooCommerce 原本的「已完成退款」信，不再多收一封內容重複的「訂單已取消」；只有沒有退款信的情況（例如全額用點數或儲值金付款、或關閉了退款通知信）才會補寄「訂單已取消」。

### 25.8.154
- 修正：顧客用儲值金折抵結帳、信用卡付款失敗後從訂單頁重新付款成功時，儲值金沒有再扣款的問題（顧客會白拿折抵）。現在重新付款前會先補扣儲值金，餘額不足時會提示並導回付款頁；任何路徑付款完成時發現折抵沒扣到，也會補扣，扣不到會在訂單備註留下警告請人工處理。

### 25.8.153
- 新增：顧客可以對「處理中」（已付款、還沒出貨）的訂單申請取消。在「我的帳號 → 訂單」按「申請取消訂單」選原因送出，店家在訂單頁審核；核准後系統自動取消整張訂單、退回庫存並全額退款（綠界信用卡同時退刷，點數與儲值金折抵一併退回）。已出貨的訂單不能取消，要收到商品後改申請退換貨；含儲值金商品的訂單需聯絡店家。可在「WooCommerce → 設定 → 退換貨」關閉這項功能。若訂單已建立綠界物流單，核准時會提醒到綠界後台取消物流單。
- 調整：會員中心不再有獨立的「退換貨」頁籤，退換貨資訊整合進原生的「訂單」頁面——訂單列表多一個「退換貨」欄，顯示該訂單的申請狀態並可點進詳情（顧客一筆申請都沒有時不加這一欄）；訂單詳情頁原本就有退換貨區塊。申請與查看詳情的流程不變，進入申請頁時選單仍停在「訂單」。
- 新增：退換貨建立退款時，如果訂單是用綠界信用卡（一次付清或分期）付款，會自動向綠界退刷，不用再到綠界後台手動處理。系統會依訂單狀態自動嘗試「取消授權」「退刷」，部分退款需要時會先關帳再退刷，每一步的結果都寫在訂單備註。
- 調整：信用卡退刷失敗（例如分期付款只退一部分、剛好在綠界每日關帳的 20:15–20:30、或綠界回報錯誤）時，WooCommerce 的退款紀錄仍會保留，訂單備註會寫明原因並提醒到綠界後台手動處理。分期付款訂單只能全額退刷。

- 新增：建立退款時會自動連動紅利點數（追回回饋、退還折抵）、儲值金折抵與庫存；金流端的退款（例如信用卡）仍需到綠界後台手動處理，系統會提醒。
