# 終極電商 (Ultimate E-commerce)

具備會員分級、動態折扣規則、優惠卡券、紅利點數系統、智能贈品與加購引擎的 WooCommerce 擴充外掛。

由 NiBill（https://nibill-studio.com/）開發維護。

## 變更紀錄

### 25.8.153
- 新增：顧客可以對「處理中」（已付款、還沒出貨）的訂單申請取消。在「我的帳號 → 訂單」按「申請取消訂單」選原因送出，店家在訂單頁審核；核准後系統自動取消整張訂單、退回庫存並全額退款（綠界信用卡同時退刷，點數與儲值金折抵一併退回）。已出貨的訂單不能取消，要收到商品後改申請退換貨；含儲值金商品的訂單需聯絡店家。可在「WooCommerce → 設定 → 退換貨」關閉這項功能。若訂單已建立綠界物流單，核准時會提醒到綠界後台取消物流單。
- 調整：會員中心不再有獨立的「退換貨」頁籤，退換貨資訊整合進原生的「訂單」頁面——訂單列表多一個「退換貨」欄，顯示該訂單的申請狀態並可點進詳情（顧客一筆申請都沒有時不加這一欄）；訂單詳情頁原本就有退換貨區塊。申請與查看詳情的流程不變，進入申請頁時選單仍停在「訂單」。
- 新增：退換貨建立退款時，如果訂單是用綠界信用卡（一次付清或分期）付款，會自動向綠界退刷，不用再到綠界後台手動處理。系統會依訂單狀態自動嘗試「取消授權」「退刷」，部分退款需要時會先關帳再退刷，每一步的結果都寫在訂單備註。
- 調整：信用卡退刷失敗（例如分期付款只退一部分、剛好在綠界每日關帳的 20:15–20:30、或綠界回報錯誤）時，WooCommerce 的退款紀錄仍會保留，訂單備註會寫明原因並提醒到綠界後台手動處理。分期付款訂單只能全額退刷。

### 25.8.152
- 新增：「退換貨」功能（併在「訂單強化」模組底下，開啟訂單強化就會啟用）。顧客在「我的帳號」可以對已完成的訂單自助申請退貨或換貨（選商品與數量、填原因、上傳照片），核准後填寫寄回的物流單號；管理員直接在 WooCommerce 的訂單管理處理：訂單列表多了「退換貨」欄位與篩選，打開訂單就能核准、拒絕、標記已收到退貨、建立退款或標記換貨完成，每一步都會記在訂單備註，並寄信通知顧客（退款通知沿用 WooCommerce 原生的「已退款的訂單」信件）。
- 新增：建立退款時會自動連動紅利點數（追回回饋、退還折抵）、儲值金折抵與庫存；金流端的退款（例如信用卡）仍需到綠界後台手動處理，系統會提醒。
- 新增：可在「WooCommerce → 設定 → 退換貨」調整申請期限、可申請的訂單狀態、申請原因、是否必須上傳照片、寄回地址與說明；個別商品與商品分類可設為不可退換。
- 調整：會員等級的消費金額現在會扣掉已退款的金額（所有退款都適用）。

### 25.8.151
- 新增：折扣規則多了「商品頁加購」。在指定的商品頁（可選商品、分類、標籤或品牌）會出現加購選項，樣式跟購物車的加購區塊一致，點整張卡片就能加購、再點一次取消，已選的卡片會有主題色外框與勾勾；加購價可以是固定金額或依原價打折。加購品數量永遠跟著主商品，加購品自己有庫存或限購一件的限制時以其上限為準；主商品從購物車移除時，加購品一起移除。
- 新增：購物車、結帳頁和迷你購物車裡，商品頁加購的主商品與加購品合併成一列（像組合商品），加購品列在主商品底下，小計是兩者合計，只有一個移除鈕。
- 新增：折扣規則（整單打折、整單折抵、階梯式折扣、免運費）可以指定付款方式，例如「用 ATM 轉帳享 95 折」「貨到付款才免運」。顧客在結帳頁選了指定的付款方式才套用，切換付款方式時金額會即時更新；購物車頁還沒選付款方式時不會套用。
- 調整：商品頁加購卡片的間距與卡片裡各元素的間距會跟著主題自訂器「商品卡片」的設定改變。

### 25.8.134
- 調整：會員中心「會員權益」頁的手機版更好瀏覽——會員等級權益總覽每個等級是一張精簡卡片（名稱列有底色，目前等級整條主色底，一眼分辨；門檻、效期、倍率排成一列，沒有內容的欄位不顯示）；點數異動紀錄不再有內部捲動框，直接跟著整頁捲動，沒有內容的「使用期限」不顯示。

### 25.8.133
- 調整：購物車「滿額進度」在手機與平板（版面上下堆疊時）改回顯示在商品列表上方，一進頁面就看得到；電腦版（總計框在右側）維持顯示在總計框最上方。

### 25.8.132
- 調整：會員中心「會員權益」頁的點數卡片改為與主題一致的外框（2px 邊框、直角、透明底），點數餘額數字使用主題主色，分隔線也跟隨主題邊框色。

### 25.8.131
- 調整：外掛更新頁的「與 WordPress 的相容性」改為顯示已測試（WordPress 7.1），不再顯示「尚未測試」。

### 25.8.130
- 新增：紅利點數的「限制獲得點數的商品」「限制兌換商品」，以及儲值中心的「限制使用的商品」，都可以改用「商品品牌」來限制（站台有建立品牌才會出現）。

### 25.8.129
- 新增：折扣規則的「適用範圍」多了「指定商品品牌」（使用 WooCommerce 內建的商品品牌，站台有建立品牌才會出現）。優惠券卡片也會顯示該券限定或排除的品牌，並讓「去購物」按鈕連到對應品牌頁；品牌限制本身由 WooCommerce 判斷。

### 25.8.128
- 新增：「系統設定 ▸ 一般設定」多了「進度條樣式」，可自訂進度條粗細與圓角（膠囊形、小圓角、直角），套用到購物車滿額進度、迷你購物車進度和會員等級進度。顏色固定跟隨主題。迷你購物車的進度文字達標時也不再變色。

### 25.8.127
- 調整：購物車頁的「滿額進度」移到右側購物車總計框最上方（點數折抵之前）；達成時文字不再變色，只靠進度條滿格表示。

### 25.8.126
- 調整：購物車頁的「滿額進度」區塊改成帶外框的卡片，風格與下方「專屬加購優惠」一致；剩餘金額用主題主色強調，進度條加粗，多筆進度之間用間距區隔。

### 25.8.125
- 調整：購物車與結帳頁總計區塊的「本次訂單使用點數」數字改為與小計、總計數字相同的文字顏色。

### 25.8.124
- 調整：會員註冊表單的生日（月/日）改為必填，沒選或日期不存在（例如 2/30）會提示重新選擇。已註冊會員在「編輯帳戶資料」頁的生日欄位不受影響。

### 25.8.123
- 新增：綠界超商物流貨態會自動更新訂單狀態——商品已送至物流中心時變「已出貨」，已送達門市時變「配送中」；消費者七天未取件時變成新的「未取件退回」狀態並留下備註，方便你決定退貨、退款或重寄。等待付款中的訂單（ATM、超商代碼）不會被貨態更動。
- 調整：購物車「點數兌換商品」區塊的點數數量顏色改為跟隨主題主色。

### 25.8.122
- 新增：自動贈品會在購物車、結帳頁與迷你購物車的商品名稱後標示「贈品」，標籤顏色跟隨主題主色。
- 新增：自動贈品規則多了「原價購買」選項，勾選後該贈品商品也可以讓顧客用原價單買；預設不勾，行為與以往相同。

### 25.8.121
- 新增：會員等級的生日禮、升等禮可以加入「免運券」。發放時會產生一張限本人使用的免運優惠券，可以跟折扣券一起用。請確認 WooCommerce 的「免運費」運送方式已設為接受免運優惠券。
- 修正：儲存會員等級禮包時，「固定金額折抵」會被改存成無法使用的類型，現在不會了。

### 25.8.120
- 修正：折扣規則、紅利點數限定回饋分類、點數兌換商品選擇「上層商品分類」時，掛在下層分類的商品沒有套用。現在上層分類會包含所有下層分類的商品。
- 調整：後台單一開／關設定改用切換開關樣式。

### 25.8.119
- 修正：後台關掉「滿額進度區塊」後，頁首迷你購物車裡的進度條仍然會顯示。現在關掉後迷你購物車也一起隱藏。

### 25.8.118
- 修正：手機版購物車與結帳頁的「點數折抵」「儲值金折抵」金額，負號會單獨換到上一行；「本次訂單使用點數」「預估獲得點數」的文字也會被拆成兩行。現在都會維持在同一行。

### 25.8.117
- 修正：佈景主題把商品列表卡片的「加入購物車」按鈕關掉時，購物車頁的「用點數兌換商品」沒有兌換按鈕、無法兌換。現在會自動補上按鈕；把價格關掉時，所需點數也會補上。加購商品區同樣修正。

### 25.8.116
- 購物車滿額進度條改成跟隨主題顏色，達標時不再固定顯示綠色。

### 25.8.115
- 新增：「紅利點數 ▸ 點數兌換商品」可以勾選「兌換商品也可以用原價直接購買」。勾選後，同一件商品顧客可以原價買，也可以用點數兌換；不勾選則維持原本只能兌換的做法。

### 25.8.114
- 購物車滿額提示拿掉表情符號，達標時只顯示文字。
- 修正：優惠券達標提示的金額會顯示成一串符號碼（例如「&#078;&#084;&#036;250」），現在正確顯示「NT$250」。

### 25.8.113
- 修正：購物車裡自動送的贈品可以直接改數量，改多少件都是 0 元。現在贈品固定 1 件，數量欄只顯示不能修改。

### 25.8.112
- 修正：測試站轉成正式站、整站搬家或複製網站後，授權會跟著資料一起被帶到新網址而繼續有效。現在網址一換，授權會立即停用，需要在新網站重新啟用一次；原網站不受影響。

### 25.8.111
- 後台「外掛」頁點「檢視版本詳情」時，可以直接看到每一版的更新項目，不用再連到 GitHub。

### 25.8.110
- 修正：用手機開後台「系統設定 ▸ 頁籤管理」與「一般設定 ▸ 商品頁頁籤」時，每一列會被撐得很高、「啟用」勾選框跑出畫面外。

### 25.8.109
- 儲值金可以自訂名稱（例如改叫「購物金」），購物車、結帳、會員中心會一起換成新名稱。
- 原本逐句自訂的「儲值金提示文字」改為固定文案；餘額與折抵金額會帶貨幣符號顯示（例如 NT$500）。

### 25.8.108
- 新增設定：用儲值金折抵的金額要不要累積紅利點數，預設不累積（與原本相同）。
- 原本可自訂的「點數提示文字」頁籤移除，改為固定文案。

### 25.8.107
- 購物車「預估獲得點數」與實際發放一致，購買儲值金商品不再顯示可獲得點數；修正可變商品設定限制商品時拿不到點數。
- 銀行轉帳、貨到付款購買的儲值金，在訂單改為「完成」時會自動入帳。
- 前台頁面不會再因為授權檢查而偶爾變慢。

### 25.8.106
- 贈品、滿額等門檻只計算一般商品，用點數兌換的商品、贈品、加購品不再算進門檻。
- 儲存折扣規則時會檢查數值，避免打折欄留空變成全站 0 元。
- 修正購物車提示中金額顯示成亂碼的問題。

### 25.8.105
- 修正儲值金在重新結帳、部分退款時扣款或退回金額不正確的問題。
- 修正使用儲值金或點數折抵後，免運門檻失效的問題。

### 25.8.104
- 回復到 25.8.100 的穩定版本（撤回 25.8.101～25.8.103）。
